### 13.A 新增功能条目

#### F17 工程接入与约束提取（★ 本轮新增）
- **接入**：需求方登记**本机既有 Android 工程根目录**（`D2=A`：平台后端**本机直读**，封装为"工程代理接口"），平台**只读**扫描，提取：
  1. **agent / AI 工程化配置**：`AGENTS.md` / `CLAUDE.md` / `.cursor/rules/*` / `.github/copilot-instructions.md` 等；
  2. **框架与依赖**：AGP / Kotlin / Gradle / JDK、`compileSdk` / `minSdk` / `targetSdk`、依赖与**版本锁定**（`libs.versions.toml`）；
  3. **架构与目录**：模块划分、`namespace` / `applicationId`、分包结构、分层、DI 框架；
  4. **代码风格与命名**：ktlint / detekt / `.editorconfig`、既有 `@+id` 命名规范；
  5. **构建与验证命令**；6. **术语与领域**（可选）。
- **每项带来源文件 + 行号 + 置信度**；无法确定的一律进《假设确认清单》（对齐 `D-A30`）。
- 约束冻结为**项目约束包**，随**项目级版本**归档，用户可编辑。
- 需求：`REQ-INTAKE-001`（接入入口 / 路径登记）、`REQ-INTAKE-002`（约束提取）。

#### F18 约束注入与工程一致性（★ 本轮新增）
- **注入**：约束包摘要注入 **PRD 审核 / 需求拆解 / Spec 生成** 三处提示词，**并列**于既有的「目标平台恒为 Android」说明。

- **门禁新增 J 组「工程一致性」**（`D6=C`：**仅在严格档 `strict` 运行**）。
- 每份 Spec 增「**§0 工程约束符合性**」小节。
