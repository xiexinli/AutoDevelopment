# 角落检查清单（Corner Checklist）

> 改编自 AWS Labs AI-DLC `core/knowledge/aidlc-product-agent/corner-checklist.md`
> 用途：S1 门禁的核心扫描器，也是各角色 Agent 写 Spec 前必过的自查。
> 核心洞见：**漏掉的缺陷不是缺失的功能，而是「角落」——一个组件遇到一个不寻常条件。**
> 没人想到要问，所以多问问题找不到它们；**把每个组件与固定条件清单做叉乘扫描才能找到。**

---

## 怎么用（五步）

1. **先定形态**：这是单用户还是多用户？本地还是联网？单租户还是多租户？是否涉及合规/个人数据？
   —— 单机本地工具可以跳过大部分身份、租户、个人数据行；受监管的多租户服务全都要保留。
2. **列组件**：用 PRD 里**已经点名的**页面、接口、任务、集成点，**不许自己新增**。
3. **叉乘**：每个组件 × 它真正会碰到的条件面。一个不读文件的组件跳过「文件与路径」。
4. **每个适用的条件，必须收敛为三态之一**：
   - 写成一条需求，或一条 Given/When/Then 验收标准；
   - 记为「假设 + 理由」（说明为什么不需要单独一条需求）；
   - 明确列入「不在范围」。
5. **只问 agent 不可能知道的事**：用户的团队、预算、账号、区域、既有系统、合规义务——这些必须问。
   靠合理默认就能定的角落，写成需求或假设让用户纠正，**不许变成问题**。

> 判定标准：**每个适用条件都要以「需求 / 假设+理由 / 明确排除」三者之一收尾。沉默的角落，就是上线后坏掉的那一个。**

## 条件清单（按面）

### 文件与路径
- **路径不存在**：指出是哪个路径、说明缺失、其余功能照常
- **权限不足**：说明哪个路径、为什么，其余功能照常
- **同一路径两种写法**（大小写、Unicode 归一化、尾部斜杠、父目录符号链接）：视为同一项，绝不重复计数
- **古怪文件名**（空格、引号、非 ASCII、超长、系统保留名）：与普通名同样处理
- **越出根目录**（符号链接、`..`、压缩包条目）：绝不读写目标目录之外；遇到环就停
- **写了一半的文件**：绝不当作完整文件读；自己的写入是原子的（先写临时再改名）
- **磁盘满 / 只读**：写入明确失败，之前的好数据仍在，**不许假报成功**
- **不认识的文件**（系统元数据、编辑器交换文件、半截下载）：忽略或报告，绝不当作数据解析
- **检查后被改动**：已索引的文件变了要重读或报告过期

### 解析的格式
- **一堆好记录里混了一条畸形的**：跳过并计数，其余正常处理
- **被截断 / 还在增长**：最后一条不完整记录是「尚未完成」，**既不是错误也不是数据**
- **未知 / 缺失 / 被改名的字段**：能懂的照常工作，其余的标记出来
- **值里含分隔符、引号、换行**：解析与写回后原样保持
- **编码**（BOM、CRLF、非法字节）：读取时不损坏文本，也不让整个输入失败
- **空输入**：显示为"暂无数据"，**与读取失败区分开**
- **重复键 / 重复记录**：有且只有一条成文规则来处理；绝不重复计数
- **恶意输入**（实体膨胀、不安全的反序列化、压缩炸弹）：用安全设置与上限解析
- **假想的外部结构**：对别的工具数据布局的任何假设（嵌套深度、命名、顺序）都要写下来并与真实数据核对

### 文本
- **空 / 纯空白**：处理一致；该有占位的地方不能留空白误导
- **超长文本 / 一个没有空格的长词**：存储与展示都不破坏布局或触顶
- **Emoji、组合字符、从右到左、不可见字符**：按**可见字符**计数、截断、比较
- **标记或控制序列**：按目标环境转义（HTML、终端、表格公式），绝不执行
- **看着相等其实不等**：比较时对大小写、空白、归一化有且只有一条成文规则

### 数字、单位与金额
- **分母为零或空**：有定义值（如 "n/a"），绝不 NaN、绝不崩
- **边界**（0、1、负数、最大值、含不含端点）：在每个界限上及其外侧都正确
- **四舍五入**：各显示部分之和等于显示的总计，否则差额要标注
- **单位**：每个量都带单位；换算只在一个地方发生
- **"未知" vs "零"**：未知、不适用、0 三者在端到端中始终可区分
- **金额**：用整数最小单位或定点小数 + 币种，**绝不用浮点**
- **没有价格或费率**：显示为未知并标记，绝不当作免费
- **估算值**：标注为估算并说明依据，绝不当成实际计费额展示

### 时间
- **时区与夏令时**：时刻带偏移量存储；"日"的边界在一个明确声明的时区里
- **时钟偏移**：时长用单调时钟，绝不为负
- **周期端点**：端点含不含写明；跨午夜、月末、闰日、年末都正确
- **并列与乱序事件**：先按时间戳，再按稳定次序键
- **不可信时间戳**（缺失、epoch 零、遥远未来）：标为可疑，不当真实事件展示
- **过期与截止**：只有一个可信时钟；恰好在截止时刻的行为有定义

### 事物标识
- **两个东西同名或同键**：保持区分，并提供足够上下文
- **一个东西有多个名字**（改名、移动、从两个来源同步）：合并或关联，绝不重复计数
- **悬空引用**：显示为已损坏或已归档；依赖它的数据保留
- **没有归属的记录**：归入一个明确的、可见的"未归属"桶，**让总数对得上**
- **外部 ID**：当作不透明字符串处理（保留前导零、大小写、长度）

### 集合与列表
- **空**：说明为空，可能的话说明原因（本来就没有/被筛掉/无权限），并给出下一步动作
- **恰好一条**：用单数措辞；图表与平均值仍然成立
- **非常多条**：靠分页、虚拟滚动或汇总保持可响应；任何上限都要写明
- **部分来源失败**：展示哪些加载成功、哪些失败；**部分合计绝不当作完整展示**
- **排序**：有明确定义的顺序与稳定次序键
- **分组小计**：小计加起来等于总计；同时属于多组或不属于任何一项的，有明确规则

### 网络与远程服务
- **调用慢或挂起**：每次调用都有超时；只有依赖它的功能降级
- **离线或服务不可用**：说明情况，本地工作仍可用，能自行恢复
- **错误状态码或异常响应体**：使用前先检查状态码与内容类型
- **重试**：绝不重复产生副作用（幂等键、带上限与抖动的退避）
- **被限流**：遵守限额、降速，并告诉用户结果被延迟
- **与对端版本不一致**：容忍对端新增字段；自己的接口有版本

### 存储与状态
- **存储不可用**：报告失败，不丢已接受的写入，无需人工重启即可恢复
- **多步写入被中断**：要么全成，要么全不
- **并发编辑**：不静默丢失任何改动；检测冲突并合并或交给用户
- **同一事实存了两份**：指定其中一份为唯一事实来源；发现分歧要能检出并修复
- **缓存 vs 源**：有明确的新鲜度界限；以源为准
- **迁移与升级**：既有数据与设置存活；新旧版本在灰度期可共存；回滚后数据仍可读

### 并发、任务与会话
- **两个操作者同时动同一条**：结果与先后执行一致
- **任务重复运行或自我重叠**：绝不与自己并发；跑两次等于跑一次
- **执行中被杀掉**（崩溃、休眠、取消）：干净重启，不留半应用结果
- **卡住的任务**：超时或心跳能发现并释放
- **旧响应后到**：只应用最新请求的结果
- **同一用户多标签页/多设备**：一处操作在别处被反映或被安全拒绝
- **反馈环**：由数据派生的状态，绝不反过来改动它所派生的数据或视图直至触发自己（状态抖动、重渲染环）

### 界面与用户输入
- **加载中 / 空 / 错误是三个不同的视图**，各自说明发生了什么、下一步做什么
- **数据过期**：显示最后更新时间，以及刷新失败
- **同一事实出现在两处**：值、单位、舍入一致，且一起更新
- **破坏性操作**：确认并指明影响范围，或提供撤销
- **非法输入**：指明是哪个字段、怎么改，**保留用户已输入的全部内容**
- **重复提交**：绝不产生重复数据
- **导航走开或会话过期时的未保存输入**：绝不静默丢弃
- **客户端校验**：可信侧也要再校验一遍
- **键盘、读屏、对比度、缩放**：所有功能都能用键盘完成；状态**绝不只靠颜色**表达

### 配置、构建与环境
- **设置缺失或非法**：有文档化的默认值，或启动时报错并指明键名与期望格式
- **多处来源冲突**（默认值、配置文件、环境变量、命令行、用户设置）：有明确优先级，并能展示最终生效值
- **本地能跑、CI 或生产挂**：能在干净检出下用锁定版本构建并通过；**被测产物就是部署产物**
- **支持平台**：明确声明并检查 OS / 运行时 / 浏览器版本，否则给出清晰提示
- **首次运行**：无历史数据、无缓存、无配置也能工作
- **第三方工具缺失、变更或挂起**：指明是哪一个、怎么修；只依赖机器可读输出与退出码；每个子进程都有超时

### 身份、安全与个人数据
> 仅当第一步的"形态判断"认定相关时才适用。
- **流程中途会话过期**：重新认证后工作继续，不丢内容
- **逐对象鉴权**：每一次读写都检查调用者对该对象的权限，包括列表、搜索、导出
- **登录中被撤销权限**：在一个明确的、很短的时间窗内生效
- **租户隔离**：没有查询、缓存键、文件路径、日志、任务会跨租户
- **密钥**：运行时从受保护的存储加载，绝不写日志或展示，可轮换
- **敏感数据出现在日志、URL、通知、导出中**：排除或脱敏
- **留存与删除**：只保留必需数据、有明确期限，且可按要求导出或删除

### AI 与智能体输出（我们自己也适用）
- **输出格式畸形**：按预期结构校验；失败则重试或上报
- **无来源的主张**：绑定到明确来源，或标为不确定
- **不可信内容操纵模型**：用定界符隔离，不能改变指令或权限
- **超出上下文上限**：明确分块或拒绝，绝不静默截断
- **有后果的动作**：权限受控、有日志、由人确认

## 五角色如何各自扫描

| 角色 | 主要扫的面 | 典型角落 |
|---|---|---|
| **UI** | 界面与用户输入、文本、集合与列表、时间 | 空列表文案、超长昵称、恰一条时的单数措辞、"最后更新于"、状态不只靠颜色 |
| **接口** | 网络与远程服务、存储与状态、并发、数字与金额 | 分页边界、幂等重放、部分来源失败时的响应形态、"未知"与"0"的区分、金额精度 |
| **App** | 界面与输入、网络、存储与状态、配置与环境 | 弱网超时、重复提交、旧响应后到、未保存输入、权限被拒兜底、多设备一致性 |
| **埋点** | 并发、会话、时间、身份标识 | 快速连点去重、断网补报、跨时区上报、未登录时 user_id 取值、会话切分 |
| **测试** | 全部（它就是按这张表写用例的） | 每条条件至少一条用例；尤其"两处同事实""迁移回滚""时钟偏移" |
