## 4 必须遵守的契约（来自基线，非可选）

1. **元素 ID**：`EL-<模块>-<三位>`，项目内全局唯一、**不可复用、不可回收**；展示时归一化为大写零填充（`EL-HOME-001` ≡ `el-home-1`）。
2. **统一响应包**：`{ code, message, data, request_id }`；失败 `message` 是**可直接展示的中文**。
3. **错误码 13 个**：`INVALID_ARGUMENT` / `UNAUTHENTICATED` / `FORBIDDEN` / `NOT_FOUND` / `VERSION_CONFLICT` / `IDEMPOTENT_REPLAY` / `PAYLOAD_TOO_LARGE` / `FORMAT_UNSUPPORTED` / `UPSTREAM_TIMEOUT` / `UPSTREAM_UNAVAILABLE` / `RATE_LIMITED` / `TASK_STALE` / `INTERNAL`。
4. **幂等**：提交类接口带 `Idempotency-Key`，同键 3s 内重放返回首次结果。
5. **乐观锁**：可编辑资源带 `version`；`PATCH`/`PUT` 须带 `If-Match`，不匹配 → `VERSION_CONFLICT`（409）。
6. **分页**：`page` / `page_size`（20/50/100）/ `q` / `sort`；稳定次序键 = `updated_at` + `id` 升序。
7. **外发大模型（P0 合规）**：首次上传/首次生成前必须弹告知；用户关闭后**生成类入口一律拦截并给原因**，**不得静默降级**。
8. **文案**：一律取 `UI-Spec §3.6` / `App-Spec §6.3` 的**逐字**文案，不得自造。
