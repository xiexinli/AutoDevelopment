# PRD：Anthropic 风格首页 App（移动端）

> 版本：v1.0 ｜ 作者：需求方 ｜ 日期：2026-10-20
> 文档状态：初稿（待 PRD 审核完善）

## 1. 背景与目标

### 1.1 背景
Anthropic 官网首页以极简克制的排版、大留白、衬线标题 + 无衬线正文、柔和的米白/陶土色调，以及克制而细腻的滚动动效著称。我们希望把这套视觉与交互语言搬到移动端，做成一个 App 的首页。

### 1.2 目标
- 做出一款**首页即可独立成立**的 App：用户打开就能感受到 Anthropic 官网的质感。
- 首页承载「品牌展示 + 内容导读 + 行动入口」三件事。
- 交互与动效还原官网的克制感，不堆砌动画。

### 1.3 成功指标（初拟，待确认）
- 首页首屏加载 P95 ≤ 2s（4G）。
- 页面滚动稳定 60fps，无明显掉帧。
- 新用户从打开到点击主 CTA 的转化率 ≥ 25%。

## 2. 目标用户与场景

| 角色 | 描述 | 核心诉求 |
|---|---|---|
| 普通访客 | 首次下载、对品牌好奇 | 快速理解「这是什么」，看到设计质感 |
| 内容读者 | 想阅读文章/公告 | 从首页进入内容列表 |
| 潜在客户 | 想了解能提供什么 | 找到联系/了解更多入口 |

**典型场景**：用户在地铁上单手打开 App，纵向滚动浏览首页各区块，点击某篇文章进入详情。

## 3. 范围

### 3.1 本期范围
- 首页（单页 + 滚动分区）
- 内容详情页（只读）
- 设置页（主题、关于）

### 3.2 不在本期范围
- 账号体系与登录
- 评论、分享到第三方
- 多语言（仅中文）
- 后台内容管理（本期内容用固定 JSON 下发）

## 4. 功能需求

### REQ-HOME-001 首屏 Hero 区
- 全屏（顶部安全区到底部）展示：品牌 Logo、主标题、副标题、一个主 CTA 按钮。
- 主标题使用衬线字体，字号大（视觉上是全页最大元素）。
- 背景色为品牌米白（#F5F2ED 级别），文字为深灰黑。
- 用户下拉到一定程度，Hero 内容渐隐 + 轻微上移（视差）。

### REQ-HOME-002 特性介绍区
- 纵向排列 3~4 个特性卡片，每张：小图标/插图 + 标题 + 一段说明。
- 卡片进入视口时淡入（fade + 轻微上移），只播放一次。
- 卡片之间大留白（≥ 48dp）。

### REQ-HOME-003 内容导读区
- 横向可滑动的文章卡片列表（3~5 张）。
- 每张卡：封面图、标题、一句摘要、发布相对时间（如「3天前」）。
- 点击卡片进入内容详情页。
- 必须处理：数据为空、加载中、加载失败三种状态。

### REQ-HOME-004 数据来源
- 特性与文章内容由服务端接口下发（本期可先用静态 JSON）。
- 需要字段：文章 id、标题、摘要、封面图 URL、发布时间、正文。

### REQ-HOME-005 主 CTA
- 页面底部固定一个主行动按钮（如「了解更多」）。
- 点击行为本期暂定为跳转外部浏览器打开官网（具体待确认）。

### REQ-NAV-001 底部导航
- 三个 Tab：首页 / 内容 / 设置。

### REQ-DETAIL-001 内容详情页
- 展示标题、正文、封面图、发布时间。
- 正文支持标题/段落/图片三种块（从 Markdown 或富文本渲染）。
- 顶部有返回按钮。

### REQ-SET-001 设置页
- 主题切换：跟随系统 / 浅色 / 深色。
- 关于：版本号、隐私政策链接。

## 6. 视觉与交互要点（参考 Anthropic 官网）

- **配色**：米白底 #F5F2ED，主文字 #1A1A1A，辅助文字 #6B6B6B，强调色陶土橙（近似 #CC785C）。
- **字体**：标题衬线（如思源宋体 / Noto Serif），正文无衬线（如思源黑体 / Noto Sans）。
- **留白**：模块间距大，内容区左右边距不少于 24dp。
- **圆角**：卡片 12~16dp，按钮全圆角或 8dp。
- **动效**：淡入、轻微位移、滚动视差；时长 300~500ms，缓动 ease-out；**不使用弹跳、旋转等强动效**。
- **暗色模式**：必须支持，另行定义一套色值。

| 兼容 | 支持小屏（5.5"）到大屏（6.7"+） |
| 离线 | 无网络时展示缓存内容 + 提示（具体策略待确认） |

## 8. 埋点（初拟）

| 事件 | 触发时机 | 目的 |
|---|---|---|
| 首页曝光 | 首页进入可见 | 统计 UV |
| Hero CTA 点击 | 点击主按钮后、跳转前 | 转化率 |
| 卡片点击 | 点击文章卡片后、跳转前 | 内容吸引力 |
| 列表滑到底 | 横向卡片滑到最后一张 | 内容是否够看 |

## 9. 验收标准（初拟）

- [ ] 首页四个区块内容齐全，文案无占位符。
- [ ] 滚动时 Hero 视差与卡片淡入正确触发，且卡片淡入只播一次。
- [ ] 内容导读区在「空 / 加载中 / 失败」三种情况下均有明确呈现。
- [ ] 点击文章卡片能进入详情页，返回后首页状态（滚动位置）保留。
- [ ] 暗色模式下所有页面文字与背景对比度符合可读性要求。
- [ ] 埋点四个事件按定义时机上报。
