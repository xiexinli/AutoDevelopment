# 后端技术栈裁决（2026-10-21）

> 编号：`D-STACK-BE-01`　｜　状态：**已裁决**（平台侧工程决策，非 PRD 需求）
> 关联：前端裁决见 `web/README.md §1`（`[待澄清-A02]` 由此关闭）

## 背景

`PRD` 与 `App-Spec §2` 只冻结了**形态约束**（SPA + 客户端路由；**单条 SSE**；本地草稿栈；自研画布渲染器），
**未指定任何服务端技术栈**。前端工程已选定 React 18 + TS + Vite（`[待澄清-A02]`），
后端需自行裁决并把决策留档，避免「换栈影响契约」。

## 裁决

| 项 | 选择 |
|---|---|
| 运行时 | Node.js ≥ 22.5（本机 v26.7.0），**直接用 `.ts` 运行**（原生类型剥离，无构建步骤） |
| HTTP 框架 | Fastify 5 |
| 存储 | SQLite（Node 内置 `node:sqlite`），单文件 `server/data/app.db` |
| 语言 | TypeScript 5.6（与前端同语言，便于共享契约类型） |

## 理由

1. **零原生编译**：`node:sqlite` 是内置模块，不引入 node-gyp / better-sqlite3 的编译风险；本机与 CI 都能直接跑。
2. **无构建步骤**：Node 的类型剥离让 `node src/server.ts` 即可启动，`tsc --noEmit` 只做类型门禁 —— CI 更简单。
3. **与前端同语言**：`接口契约` 的 13 个错误码、统一响应包、分页/幂等/乐观锁语义可以在两侧用同一套词汇表达。
4. **可迁移**：SQL 只用标准 DDL/DML，`node:sqlite` 的 API 面很窄（`prepare/run/all/get`），
   迁移到 PostgreSQL 只需替换 `src/db/index.ts` 一个文件。

## 影响与约束

- **契约不因换栈而变**：`接口契约 §0` 的所有约定（响应包 / 错误码 / 幂等 / 乐观锁 / 分页 / 逐对象鉴权 / 时间格式）
  都是**运行时行为**，与本裁决无关；换栈只需保证这些行为。
- **密钥只在服务端**：飞书应用凭据经环境变量注入（`AD_FEISHU_APP_ID` / `AD_FEISHU_APP_SECRET`），
  **绝不下发到浏览器、绝不写入日志**（`接口契约 §0.2`）。
- **不伪造**：上游不可用一律返回错误码，**不静默写入**、不预置任何业务数据。
- **未在本裁决内的**：部署形态、进程管理、鉴权网关、限流实现 —— 属运维范畴，见后续切片。
