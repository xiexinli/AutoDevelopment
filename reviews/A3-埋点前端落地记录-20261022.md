- 禁含：**不含** PRD 正文 / 生成代码 / 对话正文 / 文件名 / 项目名 / 令牌 / `open_id` 明文 / 登录表单输入。

### 6.1 最后一条：`EVT_edit_event_config` —— **PM 裁决「改挂草稿保存」并已落地**

**裁决前的死结**：该事件的埋码点原本挂在 `#40 PUT /elements/{id}/events` 的**成功回调**上，而**前端从来不调用 `#40`** —— 事件配置只写本地草稿、随草稿树经 `#42` 保存，**没有「`#40` 成功回调」可挂**，所以这条**永远接不上**。

**PM 裁决（2026-10-22）**：**改挂草稿保存**。已落地：

| 项 | 做法 |
|---|---|
| 落点 | `web/src/pages/EditPage.tsx` 的 `saveDraft` **成功之后**（与既有 `EVT_edit_element_voided` 同一套「等保存成功再报」模式） |

| 报什么 | **该元素保存后的完整事件集**（不是本次勾选的增量）—— 对齐 Spec「只报最终态」 |
| 枚举归一 | 本地 `long_press` → 对外 **`long_click`**（`接口-Spec`/`埋点-Spec` 的枚举都是 `long_click`） |
| 去重 | `dedupKey = evtcfg:{element_id}` + `dedupWindowMs: 1000`（Spec：同 `element_id` 1s 内只报 1 次） |
| 不报的情况 | ① 保存失败（不先报后回滚）；② 该元素事件被**全部取消** —— 空集不可表达（Spec 的 `count` 下限是 `1`） |
