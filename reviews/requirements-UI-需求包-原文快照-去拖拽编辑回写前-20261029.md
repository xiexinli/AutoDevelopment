### 全局 UI 约束（写 Spec 前先固化，出自已确认基线）
1. **文案口径**（`D-Q10-a`，已确认）：平台自称「**平台**」（不出现「本系统/本站」）；对使用者统一第二人称「**你**」（**不出现「需求方」「用户」等角色词**）；口吻 = 空态**积极引导**、错误态**陈述事实 + 给下一步**，**不道歉、不卖萌、不用感叹号**；中文全角标点；按钮文案不加句号。
2. **三态是三个不同视图**，不得合并（`页面规格§0.2`）：空态 = 说明 + **可点 CTA**；加载态 = 骨架/转圈 + 「正在…」，**>3s 追加进度说明**；错误态 = **可读中文原因** + **重试**，并区分 403 / 超时 / 服务不可用。
3. **破坏性操作一律二次确认 + 写明影响范围与不可撤销**（`D-A25`）：删除项目 / 删除接口 / 删除控件 / 取消能力勾选 / 版本回滚 / 重新拆解 / 重新生成。
4. **状态绝不只靠颜色**；**所有功能可用键盘完成**（含**拖拽的键盘替代**）；**未定义处按「无动效」处理并在 Spec 中显式声明**（`REQ-NF-002`）。
5. **非法输入**字段级提示 + **保留用户已输入的全部内容**；提交类按钮请求期内禁用。
6. 列表类默认 **每页 20 条、`updated_at` 倒序**（`REQ-NF-004`）；时间 **UTC 存 / 本地时区展示**，缺失**不得显示 1970**（`REQ-NF-005`）。

## 三、★ 强制清单：近似渲染与真机的差异范围（`REQ-PREVIEW-003`，UI Spec 必收）

> 依据：`§2` 第 152 行（第 4 轮授权追加的限定句）、`§2 补充块④`（`D-R3`）、`页面规格§2.3`、`AC-PV-05`、**项目约束 3**。
> 平台左侧预览 = **按安卓布局规则绘制的网页近似渲染（DOM/Canvas）**，**不是真机系统渲染**。以下差异**必须在 UI Spec 中逐条列出**，并在预览态「近似预览」标记的展开说明中呈现（**用户可见**）。

| # | 差异项 | 具体差异（至少覆盖到这一粒度） | 对用户判断的影响 |
|---|---|---|---|
| 1 | **字体度量** | 字体的字面高度、行距、字重、字距与 Android `TextView` 实际度量不同；同一 `sp` 值在网页里的占位宽度与真机不同 | 文本换行位置、单行能否放下 |
| 2 | **系统字体回退** | 真机可能回退到厂商字体（尤其中文），网页用固定字体栈 | 中文显示宽度与断行 |
| 3 | **阴影** | 网页用 CSS 近似（如 `box-shadow`），Android 用 `elevation` + 系统阴影；**`CardView` / 悬浮组件阴影最明显** | 卡片层次与视觉重量 |
| 4 | **部分控件原生外观** | `DatePicker` / `TimePicker` / `Spinner` / `SeekBar` / `RatingBar` / `Switch` / `CheckBox` / `RadioButton` **由系统主题决定实际外观**，网页只能画近似形 | 控件尺寸、选中态、系统主题差异 |
| 5 | **本地化与区域格式** | 日期/时间选择器的月份名、星期顺序、12/24 小时制随系统区域变化 | 文案与列宽 |
| 6 | **状态栏 / 导航栏 / 安全区** | 真机有状态栏、导航栏、刘海/挖孔安全区；网页以固定手机外框近似 | 顶部与底部可用高度 |
| 7 | **圆角裁剪与图片缩放** | `CardView` 圆角裁剪、`ImageView` `scaleType` 的实际裁剪方式 | 图片变形与裁切位置 |
| 8 | **`RecyclerView` / `GridView` 的 item 复用** | 网页渲染为静态列表，真机是复用视图（滚动性能、item 奇数行差异可能显现） | 列表滚动后的表现 |
| 9 | **动画与转场** | 本期**无动效**（`页面规格§6.4`），真机的系统级默认动画（如 `Toast`、`Dialog` 弹出）仍存在 | 感知上的"动" |
| 10 | **`Toast` / `Dialog`** | 二者**不是画布控件**（`数据模型 §4`），网页无法预览其真实样式 | 需要用户自行在真机确认 |

**差异清单的呈现要求**：① 预览态**常驻「近似预览」标记**；② 点开即列出上表（可用折叠/分组，但**默认可见差异项名称**）；③ 文案口吻遵循 `D-Q10-a`（陈述事实 + 给下一步，例：真机效果以你本地构建运行的结果为准）；④ **不作"接近真机"的承诺**。
