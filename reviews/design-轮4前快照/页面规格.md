## 0 全局约定

### 0.1 文案口径 ⚠️ **`[待PM确认-D-Q10-a]`**
- **平台自称**：「平台」/ 不出现「本系统」「本站」。
- **对使用者**：统一第二人称「**你**」，**不使用**「需求方」「用户」等角色词出现在文案里。
- **口吻**：空态**积极引导**（给下一步动作），错误态**陈述事实 + 给下一步**，**不道歉、不卖萌、不用感叹号**。
- **标点**：中文全角；按钮文案不加句号；提示句尾加句号。
- 例：空态写「**还没有项目。新建一个，把 PRD 丢进来。**」而不是「暂无项目数据」。
> ⚠️ 本口径属 `D-Q10`（**T1，PM 未答**）。若 PM 改为「中立书面语」，本文件所有文案按同规则重写一遍即可，**结构不变**。

### 0.2 三态定义（**三个不同的视图**，不得合并）
| 态 | 判定 | 必须包含 |
|---|---|---|
| **空态** | 请求成功，但「本来就没有」 | 说明 + 引导动作（可点的 CTA） |
| **加载态** | 请求进行中 | 骨架屏或转圈 + 「正在…」文字；超过 3s 追加进度说明 |
| **错误态** | 请求失败 / 超时 / 无权限 | **失败原因**（可读的中文）+ **重试**；区分 403 / 超时 / 服务不可用 |
`[answer:T0]`（`D-A24`）

### 0.3 通用交互规则
- **破坏性操作**一律二次确认，弹窗内**写明影响范围与不可撤销** `[answer:T0]`（`D-A25`）。
- **状态不只靠颜色**：选中 / 当前 / 失败必须有**图标或文字**伴随 `[answer:T0]`。
- **键盘可达**：所有可点元素可 Tab 到达；面板间切换有快捷键；**拖拽有键盘替代**（键盘选中控件 → 方向键微调位置）`[answer:T0]`。
- **非法输入**：字段级提示，**保留用户已输入的全部内容**。
- **重复提交**：提交类按钮在请求期内禁用；同一次意图 **3s 内只产生一次副作用**（幂等键）。

## 1 项目列表 / 新建

**入口**：登录后默认落地页 `[来源: 推断，待确认]` ｜ **出口**：进入「工作台」；或进「知识库」

### 1.1 元素构成
- 顶部：页面标题、搜索框（占位文案「搜索项目名」）、「新建项目」主按钮、用户菜单
- 工具栏：排序下拉（`最近更新`（默认）/`创建时间`/`名称`）、每页条数（20 / 50）
- 列表：项目卡片 × N，每张含 → 项目名、阶段标签、`最后更新于 X`、元素 id 前缀示例、操作（进入 / 重命名 / 删除）
- 分页器：上一页 / 页码 / 下一页（**每页 20 条，按 `updated_at` 倒序** `[answer:T0]` `D-A19`）
- 新建项目弹窗：`项目名`（必填）、`说明`（选填）、`确定` / `取消`

### 1.2 交互
| 操作 | 结果反馈 |
|---|---|
| 新建项目 | 成功 → 卡片出现在列表首位 + Toast「**项目已创建**」；失败 → **保留已填内容** + 字段级错误 |
| 重命名 | 行内编辑，成功 Toast「**名称已更新**」 |
| 删除 | 二次确认弹窗（见下），成功 → Toast「**项目已删除，30 天后彻底清除**」 |
| 连点两次「新建」 | 按钮禁用 + 幂等键，**只创建一个项目**（`D-A12`） |
| 搜索无结果 | 见错误/空态 |

### 1.3 三态与文案
| 态 | 文案 |
|---|---|
| **空态**（零项目） | 标题「**还没有项目**」；正文「新建一个项目，把 PRD 丢进来，平台会把它补到可开发。」；CTA「**新建项目**」 |
| **搜索无结果**（与空态区分） | 「**没有匹配「{关键词}」的项目。**」+ 「**清除搜索**」；**不得**显示成"还没有项目" |
| **加载态** | 骨架卡片 × 4 + 「正在加载项目…」 |
| **错误态（服务不可用）** | 「**项目列表没加载出来。**」+「原因：服务暂时不可用（{code}）。」+ 按钮「**重试**」 |
| **错误态（403）** | 「**你没有权限查看这些项目。**」（**不透露对象是否存在**）+「返回」 |
| **删除确认** | 「**删除项目「{名称}」？**」「该项目下的 Spec、接口定义、生成的安卓代码与版本历史都会一并删除，**30 天后彻底清除，期间不可恢复**。」按钮：「**删除**」（危险色 + 图标）/「取消」 |

**键盘/可达**：卡片可 Tab 聚焦，`Enter` 进入；删除需在弹窗内二次 Tab 到「删除」按钮（防误触）。

## 2 工作台（主界面）★

**入口**：从项目列表进入某项目 ｜ **出口**：上传 / 审核 / 编辑 / 测试各页

### 2.1 布局与元素构成
左右两栏 `[prd §2]`：

- **左栏 = 手机样式编辑区域 / 预览区域**（**同一区域的两个状态** `[prd §F14]` + `[prd §Q17]`）
  - 状态切换控件：分段控件「**编辑** ｜ **预览**」（**文字 + 图标，不只靠颜色**）
  - 编辑态：手机外框画布（基准宽 360dp，1dp = 3px `D-A5`）、控件面板、控件树、属性面板、事件面板
  - 预览态：渲染结果 + 顶部信息条「**生成 #{seq} · {时间}**」`D-A26`
- **右栏 = 对话框**：消息列表（用户/agent 气泡）、输入框（占位「**说说要改什么，或回答平台的问题**」）、发送按钮、停止生成按钮
- 顶部状态条：项目名、当前阶段（来自 `Project.stage`）、**门禁状态徽标**（`未审核` / `审核中` / `未通过` / `已通过`）、版本号 `v{n}`

### 2.2 交互
| 操作 | 结果反馈 |
|---|---|
| 编辑态 ↔ 预览态切换 | 立即切换；**预览态为只读**（`[prd §F9]`） |
| 样式改动 | **编辑态下即时可见**（**不**触发代码生成）`[answer:T0]` `D-Q12` |
| 提交变更（拖拽/改样式/配事件） | 生成任务入队 → 状态条显示「生成中…」→ 验证通过 → 预览自动刷新 |
| 生成中继续编辑 | **不阻塞**；提交串行化，后提交排队 `D-A12` |
| 生成失败 / 验证失败 | 两条独立路径的提示（见 2.3）；**可重试** |
| 连点发送 | 消息只发一条（幂等） |
| 空消息发送 | 禁止；输入框抖动 + 提示「**先说点什么再发送。**」 |
| 发送中继续输入 | 允许，消息入队 |
| SSE 断线 | 顶部黄色条「**连接已断开，正在重连…**」；重连后按任务序号取最新结果 |

### 2.3 预览区的三态与文案 ★（原文只有 3 态，此处补齐为 6 态）
| 态 | 文案 |
|---|---|
| **空（尚无生成结果）** | 「**还没生成过页面。**」+「在左边拖几个控件，然后提交变更。」 |
| 生成中 | 「**正在生成代码…**」（带进度百分比，来自 SSE `progress`） |
| 验证中 | 「**正在验证生成的代码…**」（L1 规则逐条打勾） |
| **生成失败**（≠ 验证失败） | 「**代码没生成出来。**」「原因：{可读原因，如"大模型超时"}。」按钮「**重新生成**」 |
| 验证失败 | 「**生成的代码没通过验证。**」「原因：{如"元素 id 与画布不一致：EL-HOME-003 缺失"}。」按钮「**重试（还剩 {n} 次）**」；`n=0` 时改为「**需要人工介入**」+「**查看验证日志**」 |
| 加载失败（渲染/资源） | 「**预览没加载出来。**」+「**重试**」 |
| **L2 未回传** | 顶部灰标「**未验证构建**」+ 悬浮说明「本地构建结果尚未回传；不影响你继续使用。」 |
| 预览与真机有差异 | 预览态右上角常驻「**近似预览**」标记，点开说明差异范围（字体度量 / 阴影 / 部分控件原生外观）`D-R3` |

**预览刷新时**：不使用动画淡入（**无动效**），直接替换并更新「生成 #{seq}」条——避免"看起来像在实时变化"的误解。

## 3 上传页

**入口**：工作台 →「上传 PRD」｜ **出口**：审核结果页

### 3.1 元素构成
- 拖拽区（虚线框，文案「**把 PRD 拖到这里，或点击选择文件**」）
- 支持格式说明：「**支持 .docx / .md / 飞书云文档链接，单文件 ≤ 20MB、≤ 100 页**」`D-A17`
- 飞书链接输入框（占位「粘贴飞书云文档链接」）
- 已选文件条目：文件名、大小、移除按钮
- 「开始解析」主按钮
- 解析进度区：分块进度（正文 / 内嵌表格 / 白板图 / 附件）

### 3.2 交互与结果反馈
| 场景 | 反馈文案 |
|---|---|
| 上传成功 | Toast「**文件已上传，开始解析。**」 |
| 上传中 | 进度条 + 「正在上传…{n}%」 |
| 格式不支持 | 「**暂不支持该格式。请上传 .docx / .md 或飞书云文档链接。**」（**不写入记录**） |
| 超 20MB | 「**文件超过 20MB（当前 {n}MB）。请压缩后重试。**」 |
| 超 100 页 | 「**文档超过 100 页（当前 {n} 页）。请拆分后分批上传。**」 |
| 空文档 | 「**这是个空文档，没有可解析的内容。**」（**与解析失败区分**） |
| 飞书链接无效 | 「**链接无效或已失效。**」+「**重新粘贴**」 |
| 飞书链接无权限 | 「**平台没有这篇文档的访问权限。**」+「**去飞书授权**」（与上一条**分开**） |
| 连点上传 | 只上传一次（幂等） |
| 上传失败（网络） | 「**上传中断了。**」+「**重试**」；已传部分**不产生半成品记录** |

### 3.3 解析结果（部分成功 ≠ 完整成功）
| 态 | 文案 |
|---|---|
| 全部成功 | 「**解析完成**」→ 自动跳审核结果页 |
| **部分成功** | 「**解析完成，但有 {n} 处没取到：**」逐条列出（如「内嵌表格 @{token}」「白板图 @{token}」）+ 每条给「**手动补充**」入口；**顶部标黄，不显示为完全成功** |
| 解析失败 | 「**解析失败了。**」「原因：{可读原因}。」+「**重试**」 |
| 超过 30s（20 页内） | 追加「**还在解析，已用 {n} 秒…**」，失败后置为可重试失败态，**不得静默卡死** |

## 4 审核结果页

**入口**：解析成功后自动进入；或工作台 →「审核结果」｜ **出口**：对话补充（F4）/ 需求拆解

### 4.1 元素构成
- 顶部：门禁结论徽标（`已通过` / **`未通过（{n} 项阻断）`**）、绑定的 `revision_id`、门禁标准版本号
- **门禁评分卡**：A~I 九类 × 检查项列表；每行 = 编号、等级、结论、**证据（章节/行号，可点击跳原文）**、完善建议
- **待澄清清单**：按等级分组（阻断 / 重要 / 建议），每条含编号、问题、**选项 A~E + `X. Other`**、兜底项、影响范围、作答框
- **完善建议区**：每条带「采纳」勾选框 + 说明
- 底部操作条：「**提交复审**」主按钮、「**一键采纳全部建议**」次按钮、「**导出审核报告**」

### 4.2 交互与结果反馈
| 操作 | 反馈 |
|---|---|
| 勾选「采纳」 | 进入**批量 Accept 候选**；⚠️ **不等于写入 PRD** —— 写入前仍需一次显式确认（`D-Q10` 待裁） |
| 「一键采纳全部建议」 | **仅批量勾选**，随后弹出确认「**确认把这些内容写回 PRD？**」→ 未确认**不写入** |
| 提交复审 | 生成新的评分卡；旧评分卡标记「**已过期**」`D-A27` |
| 提交时仍有阻断项未答 | 「**还有 {n} 项阻断没有作答，无法进入拆解。**」+ 高亮跳转 |
| 逐条作答 | 保存为草稿；**未提交即离开 → 草稿自动保存** |

### 4.3 三态与文案
| 态 | 文案 |
|---|---|
| **空态（待澄清清单 0 条）** | 「**没有待澄清项，可以直接进入拆解。**」+「**进入需求拆解**」（**与"尚未完成审核"区分**） |
| **空态（尚未审核）** | 「**还没开始审核。**」+「**开始审核**」 |
| 加载态 | 「**正在审查这份 PRD…**」（预计耗时提示；>5min 追加上限说明） |
| 错误态 | 「**审核没跑完。**」「原因：{…}。」+「**重试**」；**已出的部分结果保留展示** |
| 评分卡过期 | 「**这份评分卡已过期（PRD 已更新到 {revision}）。**」+「**重新审核**」 |
| 审核失败（agent 输出畸形） | 「**平台的输出格式不对，已自动重试一次仍失败。**」+「**需人工确认**」`D-A29` |

## 5 需求拆解页

**入口**：门禁通过后 ｜ **出口**：Spec 产出页

### 5.1 元素构成
角色需求包卡片 × 5（UI / 接口 / App / 埋点 / 测试），每张含：角色名、REQ-ID 列表、展开/收起；顶部「重新拆解」按钮；右侧「追溯矩阵」入口。

### 5.2 交互与文案
| 场景 | 文案 |
|---|---|
| 展开/收起 | 无动效，直接展开 |
| **重新拆解（破坏性）** | 弹窗「**重新拆解？**」「已生成的 5 份 Spec 会归档为历史版本（不删除），当前版本会被新结果替换。」按钮「**重新拆解**」/「取消」`D-A25` |
| 拆解中再次点击 | 拒绝并提示「**上一次拆解还没结束。**」 |
| 角色包为空 | 「**这一角色没有拆出需求。**」+「**回到对话补充**」 |
| 成功 | Toast「**拆解完成，共 {n} 条需求。**」 |

### 5.3 三态
- 加载：「**正在按角色拆分需求…**」
- 错误：「**拆解失败了。**」+「**重试**」
- 空：「**还没有需求包。**」+「**开始拆解**」

## 6 可视化编辑页 ★（本期核心交互）

**入口**：工作台左侧切到「编辑」｜ **出口**：提交变更 → 预览态

### 6.1 元素构成
| 区块 | 内容 |
|---|---|
| **控件面板** | 按 `[prd §F13]` 类别分组的**原子控件**（37 项，见《数据模型》§4）；顶部**搜索框**（占位「搜索控件」）；每项 = 图标 + 名称 |
| **手机样式画布** | 手机外框；基准宽 360dp；拖入提示；标尺线（拖拽时出现） |
| **控件树** | 层级树（缩进 + 折叠，**默认展开 3 层**）；节点 = 元素 id + 别名；与画布**双向选中同步**；树内删除/排序与画布同规则 |
| **属性面板** | **11 项全量**：宽 / 高 / 背景色 / 字体颜色 / 字体大小 / 内边距 / 外边距 / 圆角 / 边框 / 透明度 / 对齐方式 / 可见性 —— ⚠️ §8 原文只列 4 项带省略号，**本文件以 §F14 的 11 项为准**（属 `D-Q10-b` 待裁） |
| **事件面板** | **3 项**：点击 / 长按 / 双击 —— ⚠️ §8 原文漏了「双击」，**本文件以 §F14 的 3 项为准**（属 `D-Q10-c` 待裁） |
| **元素 id 显示** | 选中控件时在画布角标与面板顶部同步显示 `EL-XXX-000`（可复制） |
| 底部操作条 | 「**提交变更**」主按钮、撤销/重做、删除控件 |

### 6.2 交互与结果反馈
| 场景 | 反馈 |
|---|---|
| 拖控件入画布 | 落点用**最近容器吸附 + 插入线**指示；落点非法（画布外 / 容器层级不合法）→ **拒收 + 原因提示**「**这个位置放不了：{原因}。**」 |
| 拖入第 201 个控件 | 「**单页最多 200 个控件。**」+ 拒收 |
| 选中控件 | **三重表达**：蓝色边框 + 尺寸手柄 + 控件树高亮（不只靠颜色） |
| 改样式 | **画布即时生效**（本地）；属性面板显示实时值 |
| 输入非法值 | 字段级红框 + 气泡「**宽只能是 1~2000dp，或选「自适应 / 撑满」。**」；**已输入内容全部保留** |
| 配事件 | 勾选事件类型；默认动作显示「**暂无动作（TODO）**」（`action_type=none`） |
| 删除控件（破坏性） | 弹窗「**删除 {id}？**」「它的元素 id 会**作废且不可复用**（埋点与测试用例可能引用它）。」按钮「**删除**」/「取消」 |
| 提交变更 | 生成任务入队 → 预览态显示「正在生成…」 |
| 提交中继续编辑 | 允许；后提交排队 |
| 未提交即刷新/关闭 | 草稿**自动恢复**；恢复时提示「**已恢复上次未提交的改动。**」 |
| 未回传 L2 | 画布底部灰字「**未验证构建**」，不影响继续 |

### 6.3 三态
- 空（新页面无控件）：「**这个页面还是空的。**」+「从左边拖一个控件进来试试。」
- 加载（打开已有页面）：「**正在载入页面…**」
- 错误：「**页面没载入出来。**」+「**重试**」

### 6.4 动效
**明确无动效**：拖拽落位、面板展开/收起、选中态切换均为瞬时（降低实现复杂度，也避免与"实时预览"混淆）`[来源: 推断，待确认]`。
