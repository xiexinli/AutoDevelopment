### F3（P2 · 重要）§6 旁路清单收 `EVT_gen_spec_blocked`，却未计入「旁路 8 条」，且与附节 C 分类冲突

- **证据：**
  - `埋点-Spec:511` §6「必埋的负向（旁路）事件清单」列出一行 `EVT_gen_spec_blocked`；
  - `埋点-Spec:512` 合计算式：「**负向旁路合计 8 条** = 本表 3 条（验证失败 / 生成取消 / 写回失败）+ 本行 5 条」，**未包含 `EVT_gen_spec_blocked`**，且只对 `EVT_gen_blocked_by_egress` 写了「★合规，不另计」，**对 `EVT_gen_spec_blocked` 一字未提**；
  - `埋点-Spec:988` 附节 C 把 `EVT_gen_spec_blocked` 归为「**辅助（点击被拦）**」；

- **为什么是问题：** 同一事件在「§6 旁路表」与「附节 C 分类」下**分属两个类目**；QA 若照 §6 表格行数去数旁路，会数出与 `AC-TR-01` 口径不一致的结果。这正是本团队反复出现的「计数复扫」类缺陷。
- **最小修复（二选一，建议前者）：** 在 `:511` 该行尾补一句 ——「`EVT_gen_spec_blocked` 为**点击被拦**事件（附节 C 归「辅助」），列入本表仅为「必埋负向」齐备性，**不计入旁路 8 条**」（与 `EVT_gen_blocked_by_egress` 的处理写法对齐）；或改附节 C 分类并重算 8 条。
