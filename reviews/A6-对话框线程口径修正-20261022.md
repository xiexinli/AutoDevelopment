# A6 · 对话框线程口径修正（对象 = Project；线程 = 子步骤）

日期：2026-10-22 ｜ PM 原话：
> 「对话框的对象是 **Project 项目**，**只在新建项目及以后的步骤中显示**。**默认打开**，切换不同的子步骤后就**新切一个对话框**，**允许用户切回原来的对话框**。」

**这是对 `A5`（同日）的修正**：A5 把主体做成了「具体子对象」（打开某篇文档 / 选中某份 Spec / 正在编辑的接口 / 所选版本）。
本轮按 PM 口径**收敛为：对象恒为 Project，线程 = 项目内的子步骤**。A5 的其余部分（全局悬浮载体、AI 处理过程与补发）**保留有效**。

---

## 一、要求 → 实现对照

| PM 要求 | 实现 | 证据 |
|---|---|---|
| 对象是 **Project 项目** | 对话落在 `project_id` 上；面板头部显示**项目名**；**不再有** kb_doc/spec/api_def/version 之类的「子对象」线程 | 头部实测「对话 空项目S3核对 工作台」 |
| **只在新建项目及以后的步骤中显示** | `FloatingChat` 在 `projectId` 为空时**直接不渲染** → 项目列表页没有对话框 | 列表页无「打开对话框」按钮 ✅ |
| **默认打开** | 进入 / 切换项目时 `setOpen(true)`（子步骤之间切换保持用户当前开合状态，不强行重开） | 进入项目后面板即为展开态 ✅ |
| **切换不同子步骤 → 新切一个对话框** | 线程 = 子步骤（`workbench`/`kb`/`upload`/`review`/`split`/`editor`/`specs`/`apis`/`capabilities`/`versions`）；`#25` 按 `thread` 取线程、`#26` 落 `thread_key` | 工作台 4 条 / 上传 2 条**互不可见** ✅ |
| **允许用户切回原来的对话框** | ① 顶部「**切换对话**」下拉列出本项目**有消息的线程**（带条数），点一下切回；② 直接切回原**步骤**；手选偏离当前步骤时给「**回到当前步骤**」，**任何路由变化自动重新跟随** | 切回工作台后原对话恢复、且出现「回到当前步骤」；导航到审核步骤后自动恢复跟随 ✅ |

## 二、改了什么

### 2.1 后端

- **表结构**：`tbl_chat_message` 的 `subject_type`/`subject_id`（上一版）→ **`thread_key`**（单一列）。
  迁移用 `RENAME COLUMN` **保数据**；旧列 `subject_type` 的删除要先 `DROP INDEX idx_chat_subject`，
  否则 SQLite 会**静默拒删**留下无用列（本轮踩到并修掉）。历史消息统一归入 **`workbench`**（对话原就长在工作台右栏）。
- **`#25`**：`?thread=<子步骤>` → 取该线程；**不给 → 返回该项目全部线程**（面板一次拉取后自行分组，无需逐线程请求）；
  非法值**回落 `workbench`**（不报错）。
- **`#26`**：body `thread?`，缺省 `workbench`（**老客户端行为不变**）。序号在「项目 + 线程」内单增。
- **`#45`**：`chat.delta` 带 `thread_key`。**未新增接口、未新增实体、编号未重排**（仍 75 接口）。

### 2.2 前端

- `chat/subject.ts` → **`chat/thread.ts`**：状态 = `{projectId, stepKey, activeKey, picked}`。
  `picked` = 用户手选的线程（`null` = 跟随当前步骤），**路由变化一律清 `picked`**。
- `FloatingChat`：项目为空不渲染；默认打开；头部 = 「对话 ·**项目名** ·**线程▾**」+「回到当前步骤」；线程列表由 `ChatPanel` 经 `onThreads` 回报。
- `ChatPanel`：改为**按 `thread_key` 分组**渲染 —— 一次拉全量 → 渲染当前线程 + 回报线程概览（含条数）；发送带 `thread`。
- **删掉**上一轮加在 `KbPage`/`SpecsPage`/`ApiManagePage`/`VersionsPage` 的「具体对象」覆盖逻辑（不再需要）。

### 2.3 本轮修掉的一个真 bug

`ChatPanel` 的空态判断仍用「**项目全部消息数**」而不是「**当前线程消息数**」→ 项目有历史消息、但切到一个**空线程**时，
面板是**一片空白**（既不显示消息，也不显示空态）。已改为 `visible.length === 0`。

**浏览器真实端到端**：

| 步骤 | 实测 |
|---|---|
| 项目列表页 | **没有**对话框 ✅ |
| 进入项目 | 面板**默认展开**；头部 =「对话 · 空项目S3核对 · 工作台」；历史 4 条消息在 ✅ |
| 切到「上传」步骤 | 头部变「· 上传」；**空态**「这个步骤还没有对话。」✅ |
| 在上传步骤发一条 | 只在本线程显示，**看不到工作台的消息**（隔离）✅ |
| 打开「切换对话」 | 列出「工作台 4」「上传 2（当前步骤）」✅ |
| 点「工作台」 | 切回原对话（旧消息恢复、新消息不出现）+ 出现「**回到当前步骤**」✅ |
| 导航到「审核」步骤 | 自动**重新跟随**当前步骤（手选被清）✅ |
