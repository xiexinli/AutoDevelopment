# B8 系统设置（主题：浅色 / 深色 / 跟随系统）—— 2026-10-26

## 1 做了什么

用户菜单（顶栏右上，头像 + 昵称）里**在「退出登录」上方新增「系统设置」**（齿轮图标）；
点击弹窗，目前只有**主题**一节，三张等宽卡片：**浅色 / 深色 / 跟随系统**（形态参照用户给的参考图：
图标在上、名称在下，选中项 = 主色描边 + 主色浅底）。选择**即时生效并落盘**，无「保存」按钮。

### 1.1 换肤机制（关键设计）

不做逐组件传参，也不维护两套组件 —— **只换变量 + 换 AntD 算法**：

| 层 | 做法 |
|---|---|
| 事实来源 | `<html data-ad-theme="light|dark">`（外加 `color-scheme`，让原生控件/滚动条一起变） |
| 自定义样式 | `styles.css` 里所有颜色走 `var(--ad-*)`；深色只在 `html[data-ad-theme="dark"]` 里**覆盖变量** |
| AntD 组件 | `main.tsx` 的 `ConfigProvider` 按同一状态切 `theme.darkAlgorithm` / `defaultAlgorithm`，并换 `components` 里的 Layout/Menu/Table 取值 |
| 首屏防闪白 | `index.html` 内联脚本在样式与业务 JS 之前读 `localStorage['ad.theme']` 写好 `data-ad-theme`（规则与 `theme.ts` 一致，两处同改） |
| 「跟随系统」 | 读 `prefers-color-scheme`，并 `matchMedia('change')` **监听系统切换**（macOS 日落自动切主题时页面跟着变） |

新增文件：`web/src/theme.ts`（模式/解析/订阅）、`web/src/components/SystemSettingsModal.tsx`。
改动文件：`web/src/layout/AppShell.tsx`（菜单项 + 挂载弹窗）、`web/src/main.tsx`（算法切换 + token 拆成浅/深两套）、
`web/src/styles.css`（新增深色变量块与语义底色变量）、`web/index.html`（防闪白脚本）。

**中性色清点**：一次性把散落在各页内联样式里的中性色（`#E5E7EB`/`#F5F6F8`/`#1F2329`/`#4E5969`… 共 60 余处、
涉及 20 个文件）换成 `var(--ad-*)`；语义色（成功/警告/危险）与 `editor/Canvas.tsx`、`editor/model.ts`
里的**手机壳/预览**白底**保持原样**（那是被编辑的内容，不是应用外壳）。

### 1.2 取舍与已知边界

- **默认值 = 跟随系统**（与参考图的选中项一致）。副作用：系统是深色的机器上，第一次打开就是深色。
- 深色下的品牌色提亮一档（`#2563EB → #3B82F6`），否则深底上对比不足。
- 未做：设置弹窗里的左侧导航（账号管理 / 数据管理 / 服务协议）—— 平台没有这些功能，**不摆空壳**。
- 未做：深色下的语义色细分（内联的 `#52C41A` / `#FAAD14` 等仍是浅色主题那套值，深底下可读但不算最优）。
