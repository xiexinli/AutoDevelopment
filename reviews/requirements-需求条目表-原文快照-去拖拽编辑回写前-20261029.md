## 0 使用说明（下游 5 个角色 Agent 先读本节）

### 0.1 编号规则
| 类型 | 格式 | 说明 |
|---|---|---|
| 需求 | `REQ-<模块>-<三位>` | 本表为准。**一旦生成不得重排、复用、删除**；新增需求追加新号，不插号 |
| UI 页面 | `UI-<模块>-<三位>` | UI 角色产出 |
| UI 元素 | `EL-<模块>-<三位>` | `D-A2`：模块名 = 页面英文短名（大写，2~12 字符）；序号 001~999，溢出扩四位并在术语表登记（见 `REQ-UIEDIT-009`） |
| 接口 | `API-<模块>-<三位>` | 接口角色产出；**平台自身接口**另用 `接口契约 #n` 引用（勿与 `API-*` 混用） |
| App 路由 | `RT-<模块>-<三位>` | App 角色产出 |
| 埋点事件 | `EVT_<模块>_<动作>` | 小写下划线，全局唯一 |
| 测试用例 | `TC-<模块>-<三位>` | 测试角色产出 |

### 0.2 引用约定（**强制**）
- 跨角色引用一律用**编号**（`REQ-ID` / `EL-ID` / `UI-ID` / `API-ID` / `RT-ID` / `EVT_*` / `接口契约 #n` / `AC-*`），**不复制字段清单**——字段级口径只有一个来源：`platform/design/数据模型.md`。
- 术语一律以 `baseline/术语表.md` 为准（本次已反向回填，见该文件）；实体名一律以 `数据模型.md` 为准。
- `[来源: 推断，待确认]` 的条目**原样带标签**引用，**不阻塞开工**，不得当成已定条款（见 §0.5）。

### 0.3 优先级
`P0` = 主流程必经或合规硬项（漏做即交付不成立）；`P1` = 分支与异常；`P2` = 边角。与 `验收标准.md` 的 AC 级别对齐。
