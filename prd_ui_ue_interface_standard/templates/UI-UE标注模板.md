# Part 2 · UE 说明

## 7. 交互流程图 → R-UE-001

```
[订单列表] --点击卡片--> [订单详情]
    |                        |
    |--加载失败--> [错误态] --重试--> [订单列表]
    |--空数据----> [空态]  --去逛逛--> [商品列表]
    |--未登录----> [登录页] --返回--> [订单列表]
```

必须画出**所有分支与返回路径**。

## 8. 路由表 → R-UE-002 / R-X-008

| 路由 | 参数 | 参数来源 | 刷新后保持 | 深链接 | 守卫 |
|---|---|---|---|---|---|
| `/order/list` | `status?` | URL Query | 是 | 是 | 登录 |
| `/order/detail` | `orderNo` | URL Param | 是 | 是 | 登录 |

- 路径命名规则：`/<模块>/<资源>`
- 参数编码：URL 编码

## 9. 请求层 → R-UE-005

| 项 | 值 |
|---|---|
| 搜索防抖 | 300ms |
| 并发策略 | 取消旧请求（abort） |
| 组件卸载 | 取消未完成请求 |
| 超时 | 10s，重试 1 次 |

## 10. 鉴权 → R-UE-006 / R-UE-007

- token 过期：☐ 静默刷新　☐ 跳登录页（**二选一必填**）
- 刷新失败：清空凭证 → 跳登录页 → 登录后回到原页
- 被踢下线：弹窗「账号已在其他设备登录」→ 确认后跳登录页
- 按钮级无权限：☐ 隐藏　☐ 禁用（二选一）

## 11. 错误兜底 → R-UE-009

- ErrorBoundary：捕获渲染异常 → 错误页 + 上报
- 接口异常按 `docs/错误码文案表.csv` 的「展示形态」执行

## 12. 文案表 → R-UE-010

| 位置 | 文案 |
|---|---|
| 空态标题 | 还没有订单，去逛逛 |
| 加载失败 | 加载失败，请重试 |
| 提交按钮 | 提交订单 |
| 二次确认 | 确认取消该订单？取消后不可恢复 |

含**全部**按钮、空态、错误、二次确认文案。这是 i18n 的唯一来源。

## 13. 其他

- 动效（R-UE-004）：如「卡片展开 200ms / cubic-bezier(0.4,0,0.2,1)」
- a11y（R-UE-012）：是否支持键盘操作、是否需要 ARIA 标注
- 弹窗优先级（R-UE-014）：全局 toast > 页面弹窗 > 底部抽屉
- 跨标签页同步（R-UE-015）：登录态是否同步
