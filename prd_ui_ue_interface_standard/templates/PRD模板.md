## 4. 页面与状态 → R-PRD-012 / R-PRD-019

对**每个页面**逐项填写，缺项即 fail。

### 页面：订单列表

| 状态 | 展示 | 文案 |
|---|---|---|
| 默认 | 列表，按创建时间倒序 | — |
| 加载 | 骨架屏 6 条 | — |
| 空（首次为空） | 插画 + 按钮 | 「还没有订单，去逛逛」 |
| 空（筛选后为空） | 简单文案 | 「没有符合条件的订单」 |
| 错误 | 页面级错误 + 重试 | 「加载失败，请重试」 |
| 无网络 | 与错误区分 | 「网络不可用」 |
| 无权限 | 引导登录 | 「请先登录」 |
| 极端数据 | 超长商品名折行 2 行；数量 `999+` | — |
