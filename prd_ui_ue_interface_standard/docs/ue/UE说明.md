**返回键策略（全局唯一）**：

- 底部标签页之间切换不进入返回栈；在任一标签页按返回键，先回到该标签的根页面，再按返回键退出 App。
- 二级页面（详情、编辑、列表筛选结果）返回键回到上一级页面，并恢复上一级的滚动位置与筛选条件。
- 多入口进入同一页面时，返回键一律回到进入前的页面；从通知中心与深链接进入任务详情时，返回键回到各自的入口页。
- 提交类页面（创建任务、发布话题、资料编辑）在有未保存内容时按返回键，弹出二次确认「放弃编辑？」。

## 3. 请求层行为 → R-UE-005

| 项 | 值 |
|---|---|
| 搜索防抖 | 300ms（任务市场、智能体列表、广场搜索框） |
| 并发策略 | 同类型列表请求取消旧请求（abort），以最后一次为准 |

## 4. 鉴权与权限 → R-UE-006 / R-UE-007

- accessToken 过期：先**静默刷新**一次；刷新成功则重放原请求，用户无感知。
- 刷新失败：清空本地凭证 → 跳转 `/login` → 登录成功后回到原页面（原路由写入本地路由状态）。
- 被踢下线：收到 `AUTH_401` 且刷新失败时，弹窗提示「登录已过期，请重新登录」，确认后跳转 `/login`，不保留当前页表单内容。
- 路由守卫：见第 2 节「守卫」列。守卫失败时展示「请先登录」并跳转 `/login`。
- 按钮级权限：无权限一律**不可见**（与 PRD 第 2 节一致），不采用禁用态。
- 启动时若本地无 accessToken，直接进入 `/login`，不展示首页骨架屏。

## 5. 错误处理 → R-UE-009

- 全局 ErrorBoundary：捕获渲染异常 → 展示错误页「页面开小差了，请重启 App」并提供「上报」按钮 → 上报后不自动重启。
- 接口异常统一按 `docs/错误码文案表.csv` 的「展示形态」执行，具体如下。

| 错误码 | 展示形态 | 用户文案 | 处理动作 |
|---|---|---|---|
| OK | 静默 | — | 无 |
| SYS_500 | toast | 服务繁忙，请稍后重试 | 自动重试 1 次后仍失败则提示 |
| AUTH_401 | 弹窗 | 登录已过期，请重新登录 | 静默刷新失败后跳转登录页 |
| AUTH_403 | toast | 你没有该操作的权限 | 停留当前页 |
| USER_1001 | 字段级 | 该账号已注册，请直接登录 | 聚焦到账号输入框 |
| USER_1002 | 字段级 | 账号或密码错误，请重新输入 | 清空密码框并聚焦 |
| USER_1003 | 字段级 | 密码需为 8 至 20 位且包含大小写字母和数字 | 聚焦到密码框 |
| USER_1004 | 字段级 | 请输入有效的邮箱地址或手机号 | 聚焦到账号输入框 |
| CAPTCHA_4001 | 字段级 | 图形验证码错误，请重新输入 | 自动刷新图形验证码 |
| CODE_4002 | 字段级 | 验证码无效或已过期，请重新获取 | 聚焦到验证码框 |
| CODE_4003 | toast | 操作过于频繁，请稍后再试 | 保持倒计时 |
| TASK_2001 | 页面级 | 任务不存在或已被删除 | 提供「返回任务列表」 |
| TASK_2002 | toast | 当前任务状态不支持该操作 | 刷新任务详情 |
| TASK_2003 | toast | 该任务已超过截止时间 | 置灰执行按钮 |
| TASK_2004 | 页面级 | 你不是该任务的参与方 | 提供「返回任务列表」 |
| TASK_2005 | 弹窗 | 账户可用余额不足，无法发布该任务 | 提供「去充值」与「取消」 |
| AGENT_3001 | 页面级 | 该智能体不存在或已下架 | 提供「返回智能体列表」 |

| AGENT_3003 | toast | 你已雇佣该智能体 | 停留当前页 |

| WALLET_5002 | toast | 结算失败，请稍后重试 | 任务停留 Settling，支持下拉刷新 |
| FILE_6001 | toast | 文件大小超过限制，请压缩后重试 | 移除本次上传的文件 |
| FILE_6002 | 字段级 | 不支持该文件格式，请上传 pdf 或 png 或 jpg | 移除本次上传的文件 |

## 6. 本地存储 → R-UE-008

| 存储项 | 位置 | 生命周期 | 说明 |
|---|---|---|---|
| accessToken | 系统安全存储（Android Keystore / iOS Keychain） | 退出登录时清除 | 不写 localStorage，不进日志 |
| 用户资料缓存 | 内存 + 本地键值库 | 5 分钟 | 含 userId、nickname、avatarUrl、levelCode、atTokenBalance |
| 界面语言 language | 本地键值库 | 永久 | 应用启动时读取并作为默认语言 |
| 主题偏好 | 本地键值库 | 永久 | 取值 follow、light、dark |
| 路由状态 | 内存 + 本地键值库 | 进程存活期 | 用于登录后回到原页面 |
| 未发送的对话草稿 | 本地键值库 | 页面卸载即清除 | 按 taskId 隔离 |

不使用 Cookie，不使用浏览器 sessionStorage。

## 9. 权限申请 → R-UE-011

| 权限 | 触发时机 | 拒绝后的降级路径 |

| 通知（推送） | 首次进入首页且完成登录后 | 不阻断；在设置页保留「通知设置」入口，可再次引导开启 |

## 10. 防重复提交 → R-UE-013

- 所有提交类按钮（登录、注册、重置密码、创建任务、保存任务、发布任务、执行任务、提交交付、验收、取消任务、发起争议、发布话题、保存资料、发送消息）在请求进行中置为禁用态并展示按钮内 spinner。
- 提交按钮在请求返回前不接受第二次点击；请求超时后恢复可点。
- 幂等接口（点赞、关注、标记已读）重复调用以目标状态为准，不产生副作用。
- 列表上拉加载在同一时间只允许一个分页请求在途。

## 11. 弹窗层级与冲突 → R-UE-014

优先级由高到低：

| 层级 | 类型 | z-index Token | 冲突规则 |
|---|---|---|---|
| 1（最高） | 全局 toast | `--z-toast` | 可叠加在任意弹窗之上，3 秒后自动消失 |
| 2 | 模态弹窗（二次确认、退出登录） | `--z-modal` | 出现时其他弹窗与抽屉自动收起 |
| 3 | 底部抽屉（筛选、资料编辑、交付提交） | `--z-drawer` | 同一时刻只允许一个抽屉打开，打开新的先关闭旧的 |
| 4（最低） | 顶部条幅（网络不可用） | `--z-tabbar` 之下 | 不遮挡底部标签栏 |

- 同一时刻最多存在一个模态弹窗。
- 模态弹窗打开期间，背景禁止滚动与点击。

## 12. 无障碍 → R-UE-012

- 支持系统字体放大到 130%，放大后不出现文本截断或重叠。
- 全部可点元素提供可读名称，图标按钮必须带无障碍名（例如「返回」「关闭」「点赞」）。
- 支持外接键盘操作：主要操作（登录、保存、发送、返回）可通过键盘完成，聚焦态见 `docs/ui/UI说明.md` 第 5 节。
- 颜色对比度符合 WCAG AA（正文对比度不低于 4.5:1）。
- 不依赖颜色单独传达信息：金额方向同时以正负号表示，任务状态同时以文字标签表示。

## 13. 跨页面状态同步 → R-UE-015

- 登录态在登录页、退出登录、被踢下线三处变更时同步刷新全部标签页的守卫状态。
- 个人资料在资料编辑抽屉保存成功后，同步刷新个人中心页与首页问候语。
- 任务状态在任务详情页内变更后，返回任务列表时该条卡片状态同步更新。
- 未读通知数在标记已读后同步刷新首页角标。
- 积分余额在验收结算完成后，下次进入首页或钱包时刷新。
