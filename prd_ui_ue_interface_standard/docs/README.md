# docs/ —— 待校验文档的摆放约定

校验脚本与 AI 校验都依赖这里的位置约定。**位置错了，校验会静默漏检。**

## 目录约定

| 路径 | 内容 | 格式 |
|---|---|---|
| `docs/prd/` | 产品需求文档 | Markdown（一或多份） |
| `docs/ui/` | UI 设计说明 / 标注导出 | Markdown（设计稿本体放 Figma，这里放链接+Token+状态说明） |
| `docs/ue/` | 交互说明 | Markdown |
| `docs/api/` | 接口契约 | OpenAPI 3.x，`.yaml` / `.yml` / `.json`，可多份 |
| `docs/数据字典.csv` | ★ 字段权威源 | CSV，表头见下 |
| `docs/错误码文案表.csv` | ★ 错误码权威源 | CSV，表头见下 |

## `数据字典.csv` 表头（顺序不可变）

```csv
字段中文名,字段英文名,类型,长度精度,必填,可空性,默认值,枚举值,校验规则,示例值,所属实体
```

- `可空性` 取值只能是：`必填` / `可空null` / `可空空串`
- `枚举值` 用 `|` 分隔，如 `待支付|已支付|已取消`
- `类型` 推荐取值：`string` / `int` / `long` / `decimal` / `boolean` / `datetime` / `enum` / `array` / `object`
- **ID 类字段类型必须是 `string`**（JS `Number` 超过 2^53 丢精度）
- `所属实体` 用于区分同名字段在不同实体中的差异

## `错误码文案表.csv` 表头（顺序不可变）

```csv
错误码,HTTP状态,含义,用户文案,展示形态,触发场景,是否重试
```

- `错误码` 用业务码，如 `ORDER_2001`
- `展示形态` 取值：`toast` / `页面级` / `弹窗` / `字段级` / `静默`
- `用户文案` 必须是**最终展示给用户的原话**，不得写"提示错误"

## 注意

- 校验脚本默认**只扫描 `docs/`**，不会扫描 `standards/` 等自身目录（否则标准的"禁止词表"会把自己判失败）。
- 仓库根目录下的 `examples/` 是**反面示例**，故意留有违规内容用于验证脚本，请勿删除，也勿把它当成正确写法。
