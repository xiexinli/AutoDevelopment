# Ready 门禁清单

> 评审会**直接用这一张表**。全部阻断项 = 0 且严重项 ≤ 3 才放行进入开发。
> 规则正文见 `standards/`，编号一一对应。

---

## 使用方式

1. 先跑 `bash scripts/run_all.sh` —— 机检项自动出结果，直接把输出贴进下表
2. 再跑 `ai-validation/校验提示词.md` 中的提示词 —— AI 检项出结果
3. 人工评审判定剩余项，逐条打勾或不通过

## E. 漏判回溯（必填）

> 每次 AI 直出代码出现返工，都要回答下面这句。这是规则库进化的唯一机制。

| 返工现象 | 属于哪条规则没覆盖？ | 新增/修订规则 |
|---|---|---|
| 生成 TS 类型时数值字段的约束文本被当成枚举值 | 数据字典列错位无人查 | **R-PRD-021**（机检） |
| 状态机漏处理 7 个状态（NeedsSign/AgreementPending/NeedsAccess/NeedsReSign/SettleFailed/Paused/Failed） | 只校验了"枚举要穷举"，没校验"每个枚举都要有转移规则" | **R-PRD-022**（AI检） |
| 埋点无从实现，PRD 只说"见 UI 的跳转映射表" | 埋点未被列为需求；交叉引用只验文件存在 | **R-PRD-023**、**R-PRD-024** |
| 断点媒体查询写不出互斥规则 | 只要求"有说明"，没要求"是划分" | **R-UI-016**（机检） |
| 设计稿缺失却判定通过 | R-UI-015 判定方式错配为"机检" | **R-UI-017** + 改判 R-UI-015 |
| 请求拦截器无法判断哪些接口会返回 403 | 只校验了错误码存在，没校验 HTTP 响应声明 | **R-API-019**（机检） |
| 无法区分"公开接口"与"漏写鉴权" | security 未纳入校验 | **R-API-020**（机检） |
| 清空昵称被服务端当成"未修改" | 部分更新场景的可空性未校验 | **R-API-021**（机检） |
| Mock 覆盖率不足，前端仍在等后端 | 只要求"有 Mock"，没要求覆盖度 | **R-API-022**（AI检） |
| 凭证/流水筛选后为空，AI 自行编了空态文案 | 文案只在 UE 表校验，未与 PRD 交叉 | **R-X-009**（机检） |
| 同一份文案有"文案表"和"设计画板"两个源 | i18n 源唯一性未校验 | **R-X-010** |
| 断点常量在 PRD 与 UI 各写一份且互相冲突 | 共享常量一致性未校验 | **R-X-011** |
